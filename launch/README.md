# Launch drafts

Drafts for the person launching packmem to post from their own accounts. Nothing here is posted automatically.

- `post.md`: the launch post (blog or the GitHub README's long form)
- `hn.md`: Show HN title and first comment
- `reddit.md`: r/Python and r/node
- `x-thread.md`: a five-post thread
- `SOURCES.md`: the results file behind every number, and the labels to keep when quoting them

If a benchmark is re-run, check the numbers here against `SOURCES.md` before posting.

The drafts describe 0.1.1. Check that `npm view packmem version` and `pip index versions packmem` show it before
posting.
