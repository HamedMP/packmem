# Security policy

packmem parses untrusted input (JSON, CSV rows, database rows) in native code, so memory-safety
and denial-of-service bugs are in scope.

## Reporting a vulnerability

Please report privately through GitHub's "Report a vulnerability" button on the repository's
Security tab. Do not open a public issue for a suspected vulnerability.

Include the packmem version, the platform, and the smallest input that triggers the problem.
You should get an acknowledgement within five working days.

## Supported versions

Only the latest release receives fixes while the project is in alpha.
